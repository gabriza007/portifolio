PROJETO PRINCIPAL Web Pública + Painel Admin

Liga Caramelo

Plataforma digital para uma liga de basquete 3x3, dividida entre uma experiência pública para atletas e fãs (notícias, partidas, classificação, perfis e estatísticas) e um painel administrativo operacional para gestão de equipes, atletas, partidas, súmulas e convites.

  • Interfaces responsivas para desktop e celular com foco em hierarquia visual e consistência.
  • Fluxos de formulários, edição de perfil com upload de imagem, vínculos de equipe e controle de acesso (RBAC).
  • Integração em tempo real com Firebase, operações transacionais, testes com Jest e validação com Firebase Emulator.
App público: React TypeScript Expo React Native Web
Painel admin: Tailwind CSS 3 Firebase Jest RBAC

Sobre & Formação

Sou estudante do curso Técnico em Análise e Desenvolvimento de Sistemas (ADS) na ETE Porto Digital, em Recife, com foco em desenvolvimento web, front-end e interfaces digitais.

Combino domínio de Figma com implementação prática em React, TypeScript, HTML, CSS e JavaScript. No dia a dia, incorporo assistentes de IA generativa para acelerar prototipagem, explorar variações, investigar problemas e revisar código — sempre validando manualmente cada fluxo no navegador.
